CAKE IMAGES FOLDER
==================

This folder is where you should place your cake photos.

INSTRUCTIONS:
1. Add your cake photos here with these names:
   - cake1.jpg
   - cake2.jpg
   - cake3.jpg
   - cake4.jpg
   - cake5.jpg
   - cake6.jpg

2. Supported image formats: .jpg, .jpeg, .png, .webp

3. Recommended image specifications:
   - Dimensions: At least 800x800 pixels (square format works best)
   - File size: Keep under 500KB for fast loading
   - Format: JPG for photographs

4. Tips for good cake photos:
   - Use good lighting (natural light is best)
   - Clean background
   - Show the cake from a nice angle
   - Make sure the cake is in focus
   - Take high-resolution photos

5. To add more cakes:
   - Add more images with names like cake7.jpg, cake8.jpg, etc.
   - Edit the index.html file to add more cake cards
   - Copy an existing cake card and update the image name and details

NEED HELP?
Check the main README.md file in the root folder for detailed instructions.
